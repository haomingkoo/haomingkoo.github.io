Privacy

This site has no analytics, no advertising and no cookies. Last updated 26 October 2026.

Hosting

The site is a static website hosted on GitHub Pages. GitHub may keep standard server logs, such as IP addresses, under its own privacy statement.

Portfolio chat

If you use the “Ask about my work” chat, your question and the recent conversation are sent to a Cloudflare Worker, which passes them to AI Singapore’s SEA-LION model to write an answer.

The Worker logs request metadata such as status, timing and the length of the question. It does not log the text of your question. Your IP address is used only to limit how many questions can be sent per minute. The conversation is kept in your browser tab and disappears when you close it.

Stored in your browser

If you switch between the light and dark theme, that choice is saved in your browser’s local storage so the next page opens the same way. Nothing else is stored.

Linked apps

The live apps linked from this site run on their own subdomains and each has its own privacy notice.
